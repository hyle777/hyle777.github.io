线程基础

1. 创建新线程

  • MyThread 继承 Thread，重写 run()。

  • MyRunnable 实现 Runnable 接口，重写 run()

创建 Thread 对象：

  • Thread t = new MyThread();
  • Thread t = new Thread(MyRunnable);

使用 lambda 语法 ：

    Thread t = new Thread(() -> {
        System.out.println("start new thread!");
    });

t.start()启动线程：一个线程只能调用一次

5.线程池

  1. ExecutorService只是接口，Java 标准库提供的几个常用实现类有：
  • FixedThreadPool：线程数固定的线程池；
  • CachedThreadPool：线程数根据任务动态调整的线程池；
  • SingleThreadExecutor：仅单线程执行的线程池。
  1. Executors提供了静态方法创建不同类型的ExecutorService：

  • Executors.newFixedThreadPool(4)、Executors.newFixedThreadPool(4)、Executors.newFixedThreadPool(4)

  • submit()、shutdowm()

  1. ScheduledThreadPool可以定期调度多个任务。

进程和线程

进程：一个程序，QQ.exe Music.exe

线程:：进程的一个执行单元。开了一个进程 Typora，写字，自动保存(线程负责的)

程序的集合：一个进程往往可以包含多个线程，至少包含一个!

Java 默认有几个线程?2 个 mian、GC（垃圾回收，守护线程）

并发和并行

  • 并发：CPU 一核，模拟出来多条线程，快速交替

  • 并行：CPU 多核，多个线程可以同时执行;线程池

    提高 CPU 利用率

wait 和 sleep

  1. 来自不同类

    wait=>Object

    sleep=>Thread

  2. wait 会释放锁，sleep 不会释放锁

  3. 使用范围：

wait 写在同步代码块中，sleep 任何范围

  1. 是否捕获异常

    wait 不需要捕获

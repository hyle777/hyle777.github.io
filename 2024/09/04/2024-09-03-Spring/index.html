配置类：

@Configuration：类前，把一个类变成配置文件

@Bean：方法前，返回注入的 bean 对象

@ComponentScan(basePackgaes = “pojo”)：扫描组件，注册为 bean

POJO 类：
@Component：类前，标记为组件

业务类(使用 bean 的类)：

@ContextConfiguration ：类前，指定获取 bean 的配置文件或配置类

@Autowired 或@Resource 注入 bean

DI 依赖注入（SpringBoot）

概念：类 A 依赖类 B，创建 A 的 bean 时，需要注入 B 的 bean。Spring 使用@Autowired 来实现自动注入。

@Resource 和@Autowired

@Resource：默认按名称，然后按类型

  • 不是 Spring 提供的

@Autowired：默认按类型，多个类型则使用@Qualifier来指定

  • 多个实现类，可以在某个实现类前加@Primary标记为默认实现类

SpringMVC

请求：

路径

@RequestMapping(“/xx/xx”)：请求路径映射，方法前是路径，类前是前缀

动作：

GET：查询

POST：修改（增删改）

参数类型

  1. 查询参数：加在 URL 后面，以 ? 开头，多个参数之间使用 & 分隔。

  2. 表单参数：请求体，

    默认提交方式：application/x-www-form-urlencoded。文件上传：multipart/form-data。

    数据格式：键值对

  3. JSON 数据：请求体，

    数据格式：JSON 格式，数组[]或对象{}

获取参数

  1. 获取查询参数和表单参数：

    @RequestParam：基本类型和 String

    @ModelAttribute：集合，列表，对象

  2. 获取 JSON 数据

    @RequestBody：数组[]=>List，字典{}=>Map，对象

补充：接受日期参数

@DateTimeFormat：指定日期格式字符串。”yyyy-MM-dd HH:mm:ss”。Date 接收。

响应：

返回数据

返回文本数据或 JSON 数据（==本质都是字符串==）

@Controller：控制器 Bean

@ResponseBody：Controller 方法前加，把返回的==对象，列表，集合==转换成 JSON 数据

@RestController：上面两个的整合
